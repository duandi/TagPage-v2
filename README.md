# Tag Page v2

基于原 `TagPage` 项目重写的**零依赖本地书签导航页**。保留原有数据格式与使用习惯，同时修复已知 bug 并补齐体验细节。

## 相比原版的改动

| 项目 | 原版 | v2 |
|---|---|---|
| 依赖 | Vue2 + ElementUI + axios + vue-router + Sortable + FileSaver（约 1.2MB） | **零依赖**，原生 HTML/CSS/JS，无任何第三方库 |
| 首次打开 | localStorage 为空 → 空白墙，需手动导入 | **与原项目一致**：打开时只读本地存储，没有数据就空白，需手动添加或导入 JSON |
| 导入数据 | 导入项缺 `id`，导致删除/拖拽失效 | 自动补 `id`；合并语义为「以导入文件为准」，报告新增/更新条数 |
| 持久化 | 重写全局 `localStorage.setItem` 的黑魔法 | 存储层 `js/store.js`：**localStorage 为主**（写后回读校验）→ 空间不足时降级保存（去内嵌图标，保住书签）→ IndexedDB 兜底；并带存储状态胶囊与诊断面板 |
| 导出 | 导出当前筛选结果，可能丢数据 | 始终导出**全量**数据 |
| 标签筛选 | 固定 5 个按钮，未分类数据无法查看 | 动态生成标签 + 数量徽标，含「未分类」 |
| 搜索 | 无 | 标题/网址实时搜索（Ctrl/⌘ + K） |
| 主题 | 仅浅色 | 深色（默认）/ 浅色一键切换，记忆偏好 |
| 布局 | JS 计算磁贴尺寸 | **同原项目算法**：JS 枚举列数取最大磁贴，自适应铺满整屏，任何窗口尺寸/数据量下都不出现滚动条；间距与字号随磁贴等比缩放 |
| 图标 | URL / SVG / 文字 | 同左，兼容旧数据 |
| 拖拽排序 | Sortable.js | 原生 HTML5 拖放，筛选态自动禁用避免错乱 |
| 空状态 | 无 | 区分「无数据」与「无匹配结果」 |

## 目录结构

```
TagPage-v2/
├─ index.html          页面结构
├─ css/style.css       全部样式（含双主题 CSS 变量）
├─ js/store.js        存储层（localStorage 为主 → IndexedDB 超配额兜底）
├─ js/app.js           应用逻辑（零依赖）
├─ images/             图标按钮用图
└─ favicon.png
```

## 使用

直接双击 `index.html` 即可（数据保存在浏览器 localStorage，无需服务器）。

首次打开是**空白**的，
数据仅存于当前浏览器，换设备 / 清缓存前请先「导出 JSON」。

> 注意：请不要在受限的内嵌环境（如对话预览面板）里使用——那类环境可能禁止网页写入存储，
> 页面顶部会出现红色提示条提醒你。请直接用浏览器打开 `index.html`。

## 快捷键

- `Ctrl / ⌘ + K` 聚焦搜索
- `Esc` 关闭弹窗 / 清空搜索
- `N` 新建书签（非输入状态时）

## 数据格式

与旧版 `list.json` 完全兼容，字段：

```json
{
  "id": "id_0000",
  "title": "有道云笔记",
  "url": "https://note.youdao.com/",
  "type": "url | svg | text",
  "logo": "图片 URL 或 base64",
  "svg": "<svg>…</svg>",
  "svgColor": "可选填充色",
  "logoText": "文字图标内容",
  "logoTextColor": "文字颜色",
  "bgColor": "卡片背景色",
  "tag": "1 | 2 | 3 | 4 | 5 | 空"
}
```

标签映射：`1 Default / 2 Tools / 3 Material / 4 Google / 5 Steam`，空值为「未分类」。

## 数据维护建议

- 原数据中 78 条为「未分类」，建议在页面内补齐标签，筛选才有意义。
- 大量 base64 图标会让 JSON 体积变大（当前约 2.7MB），可用外链图片替代。
